# Provider audit and data provenance

Verified locally on 10 November 2026 with outbound HTTPS enabled. DexScreener, GeckoTerminal and Jupiter responded without credentials. One combined poll produced 73 unique mint/pool records. Solana public RPC returned finalized slot 467764738. These counts describe one observation. GMGN was absent from PATH, the usual skill directories and the standard Codex/OpenCode CLI checkout paths. No GMGN software was installed.

| Adapter | Data and access | Local scheduling |
|---|---|---|
| DexScreener | Latest public token profiles, Solana token-pair batches of up to 30 mints, name/symbol/mint search. Profiles are a selective listing. Pool prices are base-token USD marks. Missing values remain null. Published caps are 60/min for profiles and 300/min for pair/search requests. | One request per 1.2 seconds across endpoints, 60-second cache |
| GeckoTerminal | Solana trending and new pools from the first page of each feed. Pool creation timestamp is the provider's reported time. Documented one-minute upstream caching can delay appearance. | Jupiter | Recent tokens by first pool creation, joined by mint to DexScreener pool records. Holder counts, first-pool fields and token update time are optional. Keyless access is documented at 0.5 requests/second. Optional JUP_API_KEY stays on the server. | One request per 2.2 seconds across discovery and quote reads |
| Solana RPC | Public mainnet finalized account/signature/transaction reads. Published public limits may change; shared IP usage may exhaust them. | One request per 1.2 seconds, 15-second cache and 10-minute finalized transaction cache |
| GMGN | Strict allowlist for token info, token security, public wallet holdings, market trending, smart money and KOL trades. Use an existing official built CLI with optional GMGN_CLI_JS (absolute path to its dist/index.js) and GMGN_API_KEY. A manual demo read uses the published test credential for a single trending request. | One request per 4 seconds, 60-second cache; demo cache 24 hours |

A provider scheduler serializes requests, coalesces identical outstanding operations, caps response size and applies a timeout. Errors trigger exponential backoff up to five minutes, with at least one minute for HTTP 429. Longer Retry-After values take precedence. Individual failures leave other feeds operational. Each adapter exposes status, time of last successful read, cooldown and a sanitized error. Runtime timestamps are receipt times except where a provider explicitly supplies an event timestamp. A receipt time bounds local observation age only. It cannot establish the upstream price update time.

## Arbitrage coverage

Screening can compare observed USD marks across discovered venues. Quote verification requires two distinct venues, the exact mint on both legs, the exact advertised pool keys in both direct quote routes, a known venue mapping, fresh pool observations, direct USDC pairs and reported liquidity at least ten times the requested input. The mint must be an initialized original SPL Token mint with revoked freeze authority. Token-2022 restrictions, bridged symbols and multi-hop venue attribution fall outside this validator. Pump.fun bonding curves do not qualify. Jupiter mappings for Raydium, Meteora, Whirlpool and PumpSwap still require an actual route response matching the observed pool. Unknown DEX identifiers remain visible as observations.

A size is denominated in USDC with assumed USD parity. The sell quote uses the minimum output of the buy leg. The conservative net estimate uses the minimum output of the sell leg, less original USDC and both modeled round-trip network and priority costs. Quoted output already includes pool fees and price impact. The simulator does not establish future execution, account creation costs, exact compute requirements, priority bids or available balances. A 15-second lifetime limits paired quote reuse. No live opportunity or profitable route was established during the documented market smoke test.

## Coverage and rights

- Profile discovery, recent listing, trending rank and first pool creation describe distinct provider observations. Global launch coverage, complete venue coverage, mint timestamps, bonding curves, initial liquidity and migration trajectories require further evidence.
- The reference catalog was used for discovery only. No catalog scripts were imported. The official GMGN repository uses MIT for its software. GMGN service access has separate terms, and the demo key is authorized for testing. The application does not load the user's GMGN config or supply signing credentials.
- DexScreener grants limited API use subject to competition and redistribution restrictions. GeckoTerminal applies its API terms and retains rights in its data. Public read access does not confer a dataset redistribution license. The local research app stores observations for its operator. No provider data license is sublicensed by this project. Separate Jupiter data redistribution rights have not been established.
